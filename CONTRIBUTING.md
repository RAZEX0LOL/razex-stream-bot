# Contributing

Small, focused pull requests are welcome.

1. Create a branch from `main`.
2. Keep production addresses, credentials, customer data, and private configuration out of commits.
3. Add or update tests for behavior changes.
4. Run `node --test` and `node scripts/check-public-safety.mjs`.
5. Use clear English commit messages.

The project targets Node.js 22 and intentionally avoids runtime npm dependencies.
